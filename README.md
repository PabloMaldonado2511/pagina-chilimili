# pagina-chilimili

Página de pedidos de Chili Mili: gomitas con chile.

Los clientes eligen sabores, cantidad y fecha de entrega desde su celular y pagan en línea o por transferencia.

> Este repositorio es público. Nunca guardar aquí claves, contraseñas ni datos de clientes.

## Cómo funciona

- `index.html`: la página de pedidos (celular primero).
- `productos.js`: productos, precios y datos del negocio. Aquí se edita todo.
- `apps-script/pedidos.gs`: receptor de pedidos para Google Sheets. Se pega en Apps Script; ahí se escriben los correos y los datos de pago, nunca en este repositorio.
- `img/`: logo, iconos y fotos.
